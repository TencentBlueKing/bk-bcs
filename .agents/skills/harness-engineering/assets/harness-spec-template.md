## 3. Parse, Don't Validate

在数据进入系统的边界处，将原始数据**解析**为强类型的领域模型，

| 配置文件 | YAML/JSON | 配置类型 | 启动阶段 |
| 外部接口响应 | JSON | 领域模型 | Adapter 层 |
