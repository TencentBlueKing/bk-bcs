## 九、日志与可观测性


### 9.1 必须使用 Context 日志

```go
import "trpc.group/trpc-go/trpc-go/log"

// ✅ 正确：携带 TraceID，关联 Agent 调用链路
log.InfoContextf(ctx, "agent started: agent=%s input_len=%d", agentName, len(input))
log.InfoContextf(ctx, "tool called: tool=%s cost=%v", toolName, cost)
log.ErrorContextf(ctx, "tool failed: tool=%s err=%v", toolName, err)
log.InfoContextf(ctx, "agent completed: cost=%v iterations=%d tokens=%d",
    totalCost, iterations, tokenUsage)

// ❌ 错误：丢失链路信息，无法关联 TraceID
log.Infof("agent started")
fmt.Printf("tool called\n")  // 严禁
```

### 9.2 关键埋点规范

| 埋点位置 | 日志级别 | 必含字段 |
|---------|---------|---------|
| Agent 开始 | INFO | agent 名称、输入长度 |
| Tool 调用 | INFO | tool 名称、参数摘要 |
| Tool 完成 | INFO | tool 名称、耗时 |
| Tool 失败 | ERROR | tool 名称、错误信息 |
| LLM 推理 | INFO | 输入 token 数、输出 token 数 |
| Agent 完成 | INFO | 总耗时、总 token 消耗、迭代轮次 |

### 9.3 生产环境可观测性要求

- 接入伽利略或智研 LLM 监控平台，追踪 LLM 调用质量、延迟和费用
- 对 Token 消耗设置告警阈值，防止费用异常
- 记录每次 Agent 完整调用链路，便于问题排查
