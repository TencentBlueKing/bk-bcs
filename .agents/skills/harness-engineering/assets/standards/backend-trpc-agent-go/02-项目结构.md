## 二、项目结构


```
{project}/
├── proto/                        # Proto 接口定义（单一事实源）
│   └── {module}.proto
├── stub/                         # trpc-cli 生成代码（禁止手改）
│   └── {package}/
│       ├── {module}.trpc.go      # Server/Client 接口
│       └── {module}.pb.go        # 消息类型
├── cmd/
│   └── main.go                   # 服务入口
├── internal/
│   └── {module}/
│       ├── agent/                # Agent 定义层（每个 Agent 一个文件）
│       │   └── {name}_agent.go
│       ├── tools/                # Tool 工具函数（每个 Tool 独立文件）
│       │   └── {name}_tool.go
│       ├── model/                # LLM 客户端初始化与配置封装
│       │   └── model.go
│       ├── session/              # 会话状态管理
│       │   └── session.go
│       └── handler.go            # trpc Handler（请求入口）
├── conf/
│   └── trpc_go.yaml              # 服务配置
├── pkg/                          # 公共工具库（可跨服务复用）
├── Makefile
└── go.mod
```

### 目录职责说明

| 目录 | 职责 |
|------|------|
| `proto/` | 接口定义，单一事实源，修改需走评审 |
| `stub/` | trpc-cli 自动生成，禁止手动修改 |
| `agent/` | Agent 定义及编排逻辑，每个 Agent 一个文件 |
| `tools/` | Tool 函数实现，每个 Tool 独立文件，便于单独测试 |
| `model/` | LLM 客户端初始化与参数配置封装 |
| `session/` | 多轮对话的会话状态管理（历史消息、上下文窗口） |
