## 十三、构建与部署


### 13.1 Makefile 标准目标

```makefile
.PHONY: proto build test lint docker clean

# 增量更新 stub（修改 proto 后执行）
proto:
	trpc create --protofile=proto/{module}.proto --output=stub --rpconly

# 编译所有服务
build:
	go build ./...

# 运行测试
test:
	go test ./... -v -cover

# 代码检查
lint:
	golangci-lint run ./...

# 构建 Docker 镜像
docker:
	docker build -t $(IMAGE):$(TAG) .

# 清理生成文件
clean:
	find . -name "*.trpc.go" -path "*/stub/*" -delete
	find . -name "*.pb.go" -path "*/stub/*" -delete
```

### 13.2 环境变量清单（Deployment 必须配置）

| 变量 | 说明 | 注入方式 |
|------|------|---------|
| `HUNYUAN_API_KEY` | 混元 LLM API Key | Kubernetes Secret |
| `REDIS_ADDR` | Session 存储 Redis 地址 | ConfigMap |
| `REDIS_PASSWORD` | Redis 密码 | Kubernetes Secret |

### 13.3 Docker 最佳实践

| 规则 | 说明 |
|------|------|
| 多阶段构建 | 编译阶段与运行阶段镜像分离，减小最终镜像体积 |
| 最小基础镜像 | 运行阶段使用 `alpine` 或 `distroless` |
| 非 root 用户 | 运行阶段使用非 root 用户启动进程 |
| 健康检查 | 通过 trpc admin 接口（默认 `:9028/is_healthy`）暴露健康状态 |
| 环境变量注入 | 所有凭证通过 Kubernetes Secret 注入，禁止写入镜像 |
