## 十、错误处理


### 10.1 错误码定义

```go
package errors

import "trpc.group/trpc-go/trpc-go/errs"

// 业务错误码从 10000 起，避免与 trpc 框架错误码（0~999）冲突
const (
    ErrCodeInvalidInput   = 10001
    ErrCodeAgentTimeout   = 10002
    ErrCodeToolFailed     = 10003
    ErrCodeLLMUnavailable = 10004
    ErrCodeSessionExpired = 10005
)
```

### 10.2 Tool 错误分级处理

```go
func Search(ctx context.Context, args SearchArgs) (SearchResult, error) {
    // 参数校验错误：返回描述性 fmt.Errorf，透传给 LLM 让其修正后重试
    if len(args.Query) > 100 {
        return SearchResult{}, fmt.Errorf("query too long: max 100 chars, got %d", len(args.Query))
    }
    if args.MaxNum <= 0 || args.MaxNum > 20 {
        return SearchResult{}, fmt.Errorf("max_num must be between 1 and 20, got %d", args.MaxNum)
    }

    result, err := db.Query(ctx, args.Query, args.MaxNum)
    if err != nil {
        // 系统错误：详细信息只写日志，不透传给 LLM
        log.ErrorContextf(ctx, "search db query failed: %v", err)
        return SearchResult{}, errs.New(ErrCodeToolFailed, "search service temporarily unavailable")
    }
    return result, nil
}
```

### 10.3 错误处理规则

| 规则 | 说明 |
|------|------|
| 参数错误透传 | 参数校验失败返回 `fmt.Errorf`，内容描述性，LLM 可据此修正 |
| 系统错误脱敏 | DB/网络异常使用 `errs.New` 返回通用消息，详情只写日志 |
| 禁止 panic | Tool 和 Agent 中严禁 panic，错误必须通过 `error` 返回 |
| 错误码从 10000 起 | 0~999 为 trpc 框架保留 |
| 禁止忽略错误 | 禁止 `_ = err`（除非有明确注释说明原因） |
