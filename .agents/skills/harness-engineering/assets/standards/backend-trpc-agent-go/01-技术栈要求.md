## 一、技术栈要求


| 技术 | 版本要求 | 用途 |
|------|---------|------|
| Go | 1.21+ | 编程语言 |
| trpc-go | latest | 底层微服务框架 |
| trpc-agent-go | latest | AI Agent 框架 |
| trpc-cli | latest | 代码生成工具 |
| gomock | latest | 单元测试 Mock |

**框架关系**：trpc-agent-go 是 trpc-go 的 AI 上层，构建 Agent 服务时两者共同使用。必须在 `main.go` 中引入以下 import 激活内网增强能力：

```go
import _ "github.com/trpc-go/trpc-agent-go/trpc"
```
