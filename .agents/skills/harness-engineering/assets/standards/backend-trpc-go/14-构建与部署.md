## 十四、构建与部署


### 14.1 Makefile 标准目标

```makefile
.PHONY: proto build test lint docker clean

# 增量更新 stub（修改 proto 后执行）
proto:
	trpc create --protofile=proto/{module}.proto --output=stub --rpconly

# 编译所有服务
build:
	go build ./...

# 运行测试
test:
	go test ./... -v -cover

# 代码检查
lint:
	golangci-lint run ./...

# 构建 Docker 镜像
docker:
	docker build -t $(IMAGE):$(TAG) .

# 清理生成文件
clean:
	find . -name "*.trpc.go" -path "*/stub/*" -delete
	find . -name "*.pb.go" -path "*/stub/*" -delete
```

### 14.2 Docker 最佳实践

| 规则 | 说明 |
|------|------|
| 多阶段构建 | 编译阶段与运行阶段镜像分离，减小最终镜像体积 |
| 最小基础镜像 | 运行阶段使用 `alpine` 或 `distroless` |
| 非 root 用户 | 运行阶段使用非 root 用户启动进程 |
| 健康检查 | 通过 trpc admin 接口（默认 `:9028/is_healthy`）暴露健康状态 |

### 14.3 安全规范

| 规则 | 说明 |
|------|------|
| TLS 加密 | 服务间通信启用 TLS |
| 统一鉴权 | 通过 `trpc-filter/auth` 实现，禁止在 Handler 中重复鉴权 |
| 服务发现 | 调用下游必须通过北极星服务名，生产环境禁止直连 IP |
| 输入校验 | 所有外部输入通过 `trpc-filter/validation` 或手动校验 |
| SQL 注入防护 | 使用参数化查询，禁止拼接 SQL |
| 敏感数据保护 | 日志、响应中不暴露密码、Token、身份证等敏感字段 |
| 依赖安全扫描 | 定期执行 `govulncheck ./...` 扫描依赖漏洞 |
