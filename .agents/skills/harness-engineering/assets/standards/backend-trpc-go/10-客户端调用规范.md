## 十、客户端调用规范


### 10.1 创建 Proxy

```go
// ✅ 正确：通过 trpc_go.yaml 的 client.service 配置驱动，框架自动服务发现
proxy := pb.NewOrderClientProxy()
rsp, err := proxy.CreateOrder(ctx, req)

// ✅ 正确：本地开发/测试时临时指定地址
proxy := pb.NewOrderClientProxy(client.WithTarget("ip://127.0.0.1:8001"))

// ❌ 错误：生产代码中硬编码 IP
proxy := pb.NewOrderClientProxy(client.WithTarget("ip://10.0.0.1:8001"))
```

### 10.2 可测性要求

下游 proxy 必须作为 struct 字段，通过接口注入，禁止在函数内临时创建：

```go
// ✅ 正确：通过接口注入，可被 gomock 替换
type UserImpl struct {
    orderProxy pb.OrderClientProxy
}

func NewUserImpl(orderProxy pb.OrderClientProxy) *UserImpl {
    return &UserImpl{orderProxy: orderProxy}
}

// ❌ 错误：函数内临时创建，无法被测试替换
func (s *UserImpl) DoSomething(ctx context.Context, req *pb.Req) (*pb.Rsp, error) {
    proxy := pb.NewOrderClientProxy()   // 无法注入 mock
    _, _ = proxy.CreateOrder(ctx, nil)
}
```

### 10.3 Context 传递规则

- 必须将上游 `ctx` 透传给下游调用，框架通过 `ctx` 传递 trace id、染色标记等信息
- 禁止使用 `context.Background()` 替代上游 `ctx` 发起下游调用
