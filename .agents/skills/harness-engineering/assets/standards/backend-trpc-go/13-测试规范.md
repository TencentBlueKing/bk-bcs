## 十三、测试规范


### 13.1 测试分类

| 类型 | 覆盖层 | 工具 |
|------|--------|------|
| 单元测试 | Handler, Service, Utils | `go test`, testify, gomock |
| 集成测试 | Handler + DB | testcontainers |

### 13.2 Mock 生成

```bash
# 为 stub 接口生成 mock（在 go:generate 或 Makefile 中执行）
mockgen -source=stub/{module}/{module}.trpc.go \
        -destination=stub/{module}/mock_{module}.go \
        -package={module}
```

### 13.3 Handler 单元测试模板（Table Driven）

```go
func TestCreateUser(t *testing.T) {
    ctrl := gomock.NewController(t)
    defer ctrl.Finish()

    mockSvc := mock.NewMockUserService(ctrl)
    impl := NewUserImpl(mockSvc)

    tests := []struct {
        name    string
        req     *pb.CreateUserRequest
        mock    func()
        wantErr bool
    }{
        {
            name: "正常创建",
            req:  &pb.CreateUserRequest{Name: "Alice"},
            mock: func() {
                mockSvc.EXPECT().
                    Create(gomock.Any(), gomock.Any()).
                    Return(&pb.User{UserId: "123"}, nil)
            },
        },
        {
            name:    "名称为空",
            req:     &pb.CreateUserRequest{Name: ""},
            mock:    func() {},
            wantErr: true,
        },
        {
            name: "下游服务异常",
            req:  &pb.CreateUserRequest{Name: "Bob"},
            mock: func() {
                mockSvc.EXPECT().
                    Create(gomock.Any(), gomock.Any()).
                    Return(nil, errs.New(500, "internal error"))
            },
            wantErr: true,
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            tt.mock()
            _, err := impl.CreateUser(trpc.BackgroundContext(), tt.req)
            if tt.wantErr {
                assert.Error(t, err)
            } else {
                assert.NoError(t, err)
            }
        })
    }
}
```

### 13.4 测试文件组织

```
internal/{module}/
├── handler.go
├── handler_test.go          # Handler 单元测试
├── service.go
├── service_test.go          # Service 单元测试
└── service_integ_test.go    # 集成测试（build tag: //go:build integration）
```

### 13.5 检查清单

- [ ] 下游 proxy 通过接口注入（非函数内临时创建）
- [ ] 每个 Handler 方法有对应 Table Driven 单元测试
- [ ] 边界条件覆盖：空参数、下游异常、超时
- [ ] 集成测试使用 build tag 隔离，不影响普通 `go test ./...`
