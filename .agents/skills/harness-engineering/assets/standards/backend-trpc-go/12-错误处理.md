## 十二、错误处理


### 12.1 errs 包使用

```go
import "trpc.group/trpc-go/trpc-go/errs"

// 定义业务错误码（从 10000 起，避免与框架错误码 0~999 冲突）
const (
    ErrCodeUserNotFound  = 10001
    ErrCodeForbidden     = 10002
    ErrCodeInvalidParam  = 10003
)

// Handler 中返回业务错误
return nil, errs.New(ErrCodeUserNotFound, "用户不存在")

// 判断下游错误码
if errs.Code(err) == ErrCodeUserNotFound {
    // 处理用户不存在的情况
}
```

### 12.2 错误处理规则

| 规则 | 说明 |
|------|------|
| 使用 `errs.New` | 禁止用 `fmt.Errorf` 返回业务错误 |
| 错误码从 10000 起 | 0~999 为 trpc 框架保留错误码 |
| error 只用于异常 | 业务有数据同时有错误码时，将错误码放在 rsp 消息体字段中，`error` 返回 `nil` |
| 禁止忽略错误 | 禁止 `_ = err`（除非有明确注释说明原因） |
| 错误向上透传 | 非预期错误直接 `return nil, err`，不在中间层二次包装 |
