## 七、服务注册与发现（北极星）


trpc-go 通过 `plugins.registry.polaris` 配置自动完成服务注册，启动时无需额外代码。

### 7.1 服务注册

服务启动后自动向北极星注册，无需手写注册代码：

```go
// main.go - 框架自动从 trpc_go.yaml 读取配置完成注册
func main() {
    s := trpc.NewServer()
    pb.RegisterUserHandlerService(s, handler.NewUserImpl(
        service.NewUserService(),
    ))
    if err := s.Serve(); err != nil {
        log.Fatal(err)
    }
}
```

### 7.2 服务发现

客户端通过 `target: polaris://` 配置触发自动服务发现，代码侧无需感知地址：

```go
// ✅ 正确：配置文件中已配置 target: polaris://...，代码中直接创建 proxy
proxy := pb.NewUserClientProxy()
rsp, err := proxy.GetUser(ctx, &pb.GetUserRequest{UserId: id})
```
