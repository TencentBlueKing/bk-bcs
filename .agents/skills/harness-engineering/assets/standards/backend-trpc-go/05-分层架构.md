## 五、分层架构


### 5.1 三层设计

```
┌──────────────────────────────────────┐
│  Handler 层（internal/{module}/handler）│
│  - 接收 trpc 请求                     │
│  - 参数校验                           │
│  - 调用 Service 层                    │
│  - 返回响应                           │
├──────────────────────────────────────┤
│  Service 层（internal/{module}/service）│
│  - 核心业务逻辑                       │
│  - 事务管理                           │
│  - 调用 Repository 层                 │
├──────────────────────────────────────┤
│  Repository 层（internal/{module}/repo）│
│  - 数据访问抽象                       │
│  - 数据库 CRUD                        │
│  - 缓存操作                           │
└──────────────────────────────────────┘
```

### 5.2 各层规则

| 层 | 允许依赖 | 禁止依赖 |
|----|---------|---------|
| Handler | Service, stub 生成代码 | Repository, 数据库包 |
| Service | Repository, 其他 Service | 数据库包直接操作 |
| Repository | 数据库驱动, ORM | 其他 Service |

### 5.3 Handler 实现模板

```go
package handler

import (
    "context"

    "trpc.group/trpc-go/trpc-go/errs"
    pb "github.com/{org}/{project}/stub/{module}"
    "github.com/{org}/{project}/internal/{module}/service"
)

// UserImpl 实现 stub 生成的 UserServer 接口
type UserImpl struct {
    svc service.UserService
}

func NewUserImpl(svc service.UserService) *UserImpl {
    return &UserImpl{svc: svc}
}

func (s *UserImpl) CreateUser(ctx context.Context, req *pb.CreateUserRequest) (*pb.CreateUserResponse, error) {
    // 1. 参数校验
    if req.GetName() == "" {
        return nil, errs.New(errs.RetClientValidateFail, "name is required")
    }

    // 2. 调用 Service 层
    user, err := s.svc.Create(ctx, req)
    if err != nil {
        return nil, err
    }

    // 3. 返回响应
    return &pb.CreateUserResponse{User: user}, nil
}
```
