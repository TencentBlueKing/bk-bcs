## 八、服务发现扩展


### 8.1 内置支持方案

| 方案 | target 前缀 | 适用场景 |
|------|------------|---------|
| 北极星（Polaris） | `polaris://` | 生产环境标准方案 |
| IP 直连 | `ip://host:port` | 本地开发、测试、固定地址场景 |
| DNS | `dns://hostname:port` | 依赖 DNS 解析的场景 |

### 8.2 自定义 Selector（接入其他注册中心）

trpc-go 没有官方 etcd 服务注册发现插件。若团队基础设施使用 etcd 或其他注册中心，需实现 `selector.Selector` 接口：

```go
import (
    "trpc.group/trpc-go/trpc-go/naming/registry"
    "trpc.group/trpc-go/trpc-go/naming/selector"
)

// 1. 实现 Selector 接口
type EtcdSelector struct {
    // etcd client 等依赖
}

func (s *EtcdSelector) Select(serviceName string, opts ...selector.Option) (*registry.Node, error) {
    // 从 etcd 查询节点列表，按负载均衡策略返回选中节点
    return &registry.Node{Address: "host:port"}, nil
}

// 2. 注册自定义 Selector（必须在 trpc.NewServer() 之前）
func init() {
    selector.Register("etcd", &EtcdSelector{})
}
```

```yaml
# conf/trpc_go.yaml - 使用自定义前缀
client:
  service:
    - name: trpc.{app}.{server}.{Service}
      target: etcd://trpc.{app}.{server}.{Service}
      protocol: trpc
```

> **注意**：自定义 Selector 需自行负责节点注册、Watch 监听、心跳保活的全部逻辑，实现与运维成本较高。在选型阶段应优先考虑北极星，避免自行维护服务发现层。
