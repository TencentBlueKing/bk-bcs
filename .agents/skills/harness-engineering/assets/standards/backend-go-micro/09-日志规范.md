## 九、日志规范


### 9.1 日志级别

| 级别 | 使用场景 |
|------|---------|
| DEBUG | 开发调试信息，生产环境关闭 |
| INFO | 正常业务流程记录（启动、请求、关键操作） |
| WARN | 非预期但可恢复的状况（重试、降级） |
| ERROR | 错误但服务仍可运行（请求失败、外部依赖异常） |
| FATAL | 不可恢复错误，服务需要退出 |

### 9.2 结构化日志

```go
import "go.uber.org/zap"

// ✅ 正确：结构化日志
logger.Info("user created",
    zap.String("user_id", userID),
    zap.String("name", name),
    zap.Duration("latency", duration),
)

// ❌ 错误：字符串拼接
logger.Info(fmt.Sprintf("user %s created, name: %s", userID, name))
```

### 9.3 日志规则

| 规则 | 说明 |
|------|------|
| 禁止打印敏感信息 | 密码、Token、身份证号等 |
| 请求日志 | 包含 request_id、方法名、耗时 |
| 错误日志 | 包含完整错误链（`%w` 或 `zap.Error`） |
| 避免高频日志 | 循环内不打 INFO 日志 |
