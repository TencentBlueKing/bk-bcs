## 二、项目结构


```
{project}/
├── api/proto/                    # Proto 接口定义
│   └── {module}/
│       ├── {module}.proto        # 接口定义（源文件）
│       ├── {module}.pb.go        # (生成) 消息类型
│       ├── {module}_grpc.pb.go   # (生成) gRPC 接口
│       ├── {module}.pb.micro.go  # (生成) go-micro 接口
│       └── {module}.pb.gw.go    # (生成) grpc-gateway
├── cmd/                          # 服务入口
│   ├── gateway/
│   │   └── main.go              # 集中式 HTTP 网关
│   └── {module}-server/
│       └── main.go              # 微服务入口
├── configs/                      # 配置文件（YAML）
│   ├── gateway.yaml
│   └── {module}-server.yaml
├── deploy/                       # 部署配置
│   └── docker/
├── internal/                     # 内部业务逻辑（不对外暴露）
│   └── {module}/
│       ├── handler.go           # gRPC Handler（请求处理）
│       └── service.go           # 业务逻辑实现
├── pkg/                          # 公共库（可跨服务复用）
│   ├── config/config.go         # 配置加载
│   ├── log/log.go               # 日志封装
│   ├── registry/registry.go     # etcd 服务注册
│   ├── resolver/resolver.go     # gRPC 服务发现解析器
│   ├── server/
│   │   ├── http.go              # HTTP Gateway 工具
│   │   └── marshaler.go         # JSON 响应包装器
│   └── task/                    # 异步任务框架（可选）
├── scripts/                      # 构建脚本
│   ├── gen-proto.sh             # Proto 代码生成
│   └── gen-openapi.sh           # OpenAPI 生成
├── third_party/                  # 第三方 Proto 依赖
│   └── google/
├── go.mod
├── go.sum
├── Makefile
└── README.md
```

### 目录职责说明

| 目录 | 职责 | 可见性 |
|------|------|--------|
| `api/proto/` | 接口定义（单一事实源） | 对外（定义契约） |
| `cmd/` | 程序入口，初始化服务 | 对外 |
| `internal/` | 业务逻辑实现 | 仅当前项目可见 |
| `pkg/` | 通用工具库 | 可被其他项目引用 |
| `configs/` | 运行时配置 | 运维相关 |
