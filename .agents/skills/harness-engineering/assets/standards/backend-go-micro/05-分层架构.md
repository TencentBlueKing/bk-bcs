## 五、分层架构


### 5.1 三层设计

```
┌─────────────────────────────────────┐
│  Handler 层（cmd/ 或 internal/handler）│
│  - 接收 gRPC/HTTP 请求              │
│  - 参数校验                          │
│  - 调用 Service 层                   │
│  - 返回响应                          │
├─────────────────────────────────────┤
│  Service 层（internal/service）       │
│  - 核心业务逻辑                      │
│  - 事务管理                          │
│  - 调用 Repository 层               │
├─────────────────────────────────────┤
│  Repository 层（internal/repository） │
│  - 数据访问抽象                      │
│  - 数据库 CRUD                       │
│  - 缓存操作                          │
└─────────────────────────────────────┘
```

### 5.2 各层规则

| 层 | 允许依赖 | 禁止依赖 |
|----|---------|---------|
| Handler | Service, Proto 生成代码 | Repository, 数据库包 |
| Service | Repository, 其他 Service | 数据库包直接操作 |
| Repository | 数据库驱动, ORM | 其他 Service |

### 5.3 Handler 实现模板

```go
package handler

import (
    "context"
    pb "your-module/api/proto/user"
    "your-module/internal/user/service"
)

type UserHandler struct {
    svc *service.UserService
}

func NewUserHandler(svc *service.UserService) *UserHandler {
    return &UserHandler{svc: svc}
}

func (h *UserHandler) CreateUser(ctx context.Context, req *pb.CreateUserRequest, rsp *pb.CreateUserResponse) error {
    // 1. 参数校验
    if req.GetName() == "" {
        return fmt.Errorf("name is required")
    }

    // 2. 调用 Service
    user, err := h.svc.Create(ctx, req)
    if err != nil {
        return err
    }

    // 3. 填充响应
    rsp.User = user
    return nil
}
```
