## 十一、测试规范


### 11.1 测试分类

| 类型 | 覆盖层 | 工具 |
|------|--------|------|
| 单元测试 | Service, Utils | `go test`, testify |
| 集成测试 | Handler + DB | testcontainers |
| E2E 测试 | HTTP API | httptest |

### 11.2 测试文件组织

```
internal/user/
├── service.go
├── service_test.go      # 单元测试
└── service_integ_test.go # 集成测试（build tag: //go:build integration）
```

### 11.3 Mock 策略

| 依赖 | Mock 方式 |
|------|----------|
| 数据库 | Interface + Mock 实现 |
| 外部服务 | gRPC Mock Server |
| 时间 | 注入 `clock` 接口 |
| 配置 | 测试专用配置文件 |
