## 十、错误处理


### 10.1 错误定义

```go
package errors

import "google.golang.org/grpc/codes"

type BizError struct {
    Code    codes.Code
    Message string
    Detail  string
}

var (
    ErrNotFound     = &BizError{Code: codes.NotFound, Message: "资源不存在"}
    ErrPermission   = &BizError{Code: codes.PermissionDenied, Message: "无权限"}
    ErrInvalidParam = &BizError{Code: codes.InvalidArgument, Message: "参数错误"}
)
```

### 10.2 错误传播规则

| 规则 | 说明 |
|------|------|
| 包装错误 | 使用 `fmt.Errorf("context: %w", err)` |
| 不隐藏错误 | 禁止 `_ = err`（除非有明确注释说明原因） |
| 用户友好 | Handler 层转换为用户可读消息 |
| 日志记录 | Service 层记录错误日志，Handler 层不重复记录 |
