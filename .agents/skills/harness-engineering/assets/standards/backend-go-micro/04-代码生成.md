## 四、代码生成


### 4.1 工具安装

```bash
# protoc-gen-go：生成 Go 消息代码
go install github.com/golang/protobuf/protoc-gen-go@v1.5.2

# protoc-gen-micro：生成 go-micro 接口
go install go-micro.dev/v5/cmd/protoc-gen-micro@v5.12.0

# protoc-gen-grpc-gateway：生成 HTTP 网关
go install github.com/grpc-ecosystem/grpc-gateway/v2/protoc-gen-grpc-gateway@v2.27.5

# protoc-gen-openapiv2：生成 OpenAPI 文档
go install github.com/grpc-ecosystem/grpc-gateway/v2/protoc-gen-openapiv2@v2.27.5
```

### 4.2 生成命令

```bash
protoc --proto_path=. \
    --proto_path=../../third_party \
    --go_out=. --go_opt=paths=source_relative \
    --go-grpc_out=. --go-grpc_opt=paths=source_relative \
    --micro_out=. --micro_opt=paths=source_relative \
    --grpc-gateway_out=allow_delete_body=true,register_func_suffix=Gw:. \
    {module}.proto
```

### 4.3 生成文件说明

| 文件 | 用途 | 修改规则 |
|------|------|---------|
| `{module}.pb.go` | 消息类型定义 | **禁止手改** |
| `{module}_grpc.pb.go` | gRPC server/client 接口 | **禁止手改** |
| `{module}.pb.micro.go` | go-micro Handler 接口和 Client | **禁止手改** |
| `{module}.pb.gw.go` | grpc-gateway HTTP 路由注册 | **禁止手改** |
