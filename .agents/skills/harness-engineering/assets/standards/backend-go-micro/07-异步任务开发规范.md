## 七、异步任务开发规范


### 7.1 适用场景

| 场景 | 说明 |
|------|------|
| 耗时操作 | 超过 30 秒的操作（如资源创建、批量处理） |
| 多步骤流程 | 需要编排多个步骤的复杂流程 |
| 需要重试 | 可能失败需要自动重试的操作 |
| 状态追踪 | 需要向用户展示进度的操作 |

### 7.2 核心概念

| 概念 | 说明 |
|------|------|
| Task | 任务，由多个 Step 组成 |
| Step | 最小执行单元，实现具体操作 |
| Callback | 任务完成后的回调（成功/失败） |
| CommonParam | 全局参数，所有 Step 可读取 |
| StepParam | 步骤私有参数，仅当前 Step 可用 |

### 7.3 Step 开发规范

```go
package mystep

import "your-project/pkg/task/istep"

const StepName = "domain-action-resource"  // 全局唯一！

type myStep struct{}

func NewStep() istep.Step {
    return &myStep{}
}

func init() {
    // 注册（名称全局唯一，重复注册会 panic）
    istep.Register(StepName, NewStep())
}

func (s *myStep) Alias() string   { return "执行某操作" }
func (s *myStep) GetName() string { return StepName }

func (s *myStep) Execute(c *istep.Context) error {
    // 读取公共参数
    userID, _ := c.GetCommonParam("user_id")
    // 读取步骤私有参数
    target, _ := c.GetParam("target")

    // 执行业务逻辑...
    return nil
}
```

### 7.4 检查清单

- [ ] Step 名称全局唯一（创建前全局搜索确认）
- [ ] Callback 名称全局唯一
- [ ] `init()` 中调用了 `istep.Register()`
- [ ] 服务入口 `main.go` 中空导入了 Step 包
- [ ] Task 的 Builder 中设置了 CallbackName
- [ ] 公共参数和步骤参数正确传递
