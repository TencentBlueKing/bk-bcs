## 八、配置管理


### 8.1 配置文件结构（YAML）

```yaml
# configs/{module}-server.yaml
server:
  name: "{module}-service"
  address: ":8080"
  http_address: ":8081"

registry:
  endpoints:
    - "etcd-host:2379"
  tls:
    cert_file: "/path/to/cert.pem"
    key_file: "/path/to/key.pem"
    ca_file: "/path/to/ca.pem"

database:
  dsn: "user:pass@tcp(host:3306)/dbname?charset=utf8mb4"
  max_open_conns: 100
  max_idle_conns: 10

log:
  level: "info"
  format: "json"
  output: "stdout"
```

### 8.2 配置加载规则

| 规则 | 说明 |
|------|------|
| 环境变量优先 | 环境变量覆盖配置文件 |
| 敏感信息 | 密码、Token 必须通过环境变量或 Secret 注入 |
| 默认值 | 所有配置项必须有合理默认值 |
| 校验 | 启动时校验必填配置，缺失则 Fatal 退出 |
