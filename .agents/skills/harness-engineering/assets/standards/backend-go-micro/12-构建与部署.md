## 十二、构建与部署


### 12.1 Makefile 标准目标

```makefile
.PHONY: proto build test lint docker

# 生成 Proto 代码
proto:
	./scripts/gen-proto.sh

# 编译所有服务
build:
	go build ./...

# 运行测试
test:
	go test ./... -v -cover

# 代码检查
lint:
	golangci-lint run ./...

# 构建 Docker 镜像
docker:
	docker build -t $(IMAGE):$(TAG) .

# 清理生成文件
clean:
	find . -name "*.pb.go" -delete
	find . -name "*.pb.gw.go" -delete
	find . -name "*.pb.micro.go" -delete
```

### 12.2 Docker 最佳实践

| 规则 | 说明 |
|------|------|
| 多阶段构建 | 编译阶段 + 运行阶段分离 |
| 最小基础镜像 | 使用 `alpine` 或 `distroless` |
| 非 root 用户 | 运行阶段使用非 root 用户 |
| 健康检查 | 配置 `HEALTHCHECK` 指令 |
