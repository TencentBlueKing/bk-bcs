# 页面原型 Spec 模板

## 使用时机

页面原型 Spec 在 PRD 完成之后、角色拆单之前生成，用于把产品方案转成可评审、可还原的页面说明。它是 BKUI HTML 原型、原型评审、产品评审和后续设计/前端/后端拆单的输入材料。

## 输出路径

建议输出到当前需求工作目录：

- 单页面：`workflows/issue-<iid>/prototype-spec.md`
- 多页面：`workflows/issue-<iid>/prototype-specs/<页面名>.md`

## BKUI 组件要求

- 页面原型生成以本仓参考文件为执行依据。
- 优先使用 BKUI 语义表达页面结构、表格、表单、按钮、弹窗、抽屉、状态反馈。
- 写清组件选择原因、关键属性、默认值和需要展示的状态。
- 无法直接表达的复杂交互，补充静态说明和 Mock 状态。
