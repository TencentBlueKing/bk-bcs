# 子需求文档模板

本模板用于需求拆分后生成规范化的子需求 Markdown 文档。Agent 应根据拆分结果填写
各章节，信息充分的详细填写，信息不足的标注"待确认"。

---

## 模板使用说明

### 拆分阶段填写

由 `tapd-story-breakdown` 在拆分阶段填写以下章节：
- 基本信息（除"规模（size，规模斐波那契）"、"预估工时（PERT E）"和"业务价值（RICE）"外）
- 依赖关系
- 接口契约定义（仅"接口契约构建"子需求填写；启用契约先行时）
- 需求背景
- 用户故事
- 功能需求
- 非功能需求
- 验收标准
- 边界范围
- 子需求文档保存路径遵循父子目录隔离：`docs/reqs/<父需求目录名>/<子需求名>.md`

### 评分阶段填写

由 `tapd-story-score` 在评分阶段补充以下章节：
- 基本信息中的"规模（size，规模斐波那契）"、"预估工时（PERT E）"和"业务价值（RICE）"
- 人力与工时
- 需求类型
- 工时估算
- 规模评分（size，斐波那契）
- 业务价值（RICE）

### 文档质量标准

- 避免使用"较快""较好""灵活"等模糊词汇
- 所有性能指标必须使用可量化的数字
- 验收标准必须使用 Given-When-Then 格式
- 验收标准必须包含所有功能点
- 每个功能点必须有输入/输出说明
