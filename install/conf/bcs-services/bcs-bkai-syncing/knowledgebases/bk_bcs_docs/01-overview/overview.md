# 产品简介与核心优势

## 什么是蓝鲸容器管理平台（BCS）

蓝鲸容器管理平台（**BCS，BlueKing Container Service**）是腾讯蓝鲸智云推出的**高度可扩展、灵活易用的企业级容器编排与服务治理平台**，全面支持社区原生 **Kubernetes（K8S）** 编排引擎。

通过 BCS，用户无需深入关注底层基础设施的复杂安装与维护，只需在 Web 控制台进行可视化配置或调用标准 API，即可完成多云与私有化 Kubernetes 集群的创建、导入与生命周期管理，实现容器应用的一站式部署、扩缩容、可观测性监控及游戏等复杂业务场景的精细化编排。

---

## 容器服务快速上手三步走

在 BCS 上运行容器化应用通常只需以下三个核心步骤：

1. **准备项目与集群**：在 BCS 创建或进入项目，关联蓝鲸配置平台（CMDB）业务，通过**新建集群**（K8S 原生集群或公有云集群）或**导入外部集群**（云凭证或 Kubeconfig）添加 Kubernetes 集群。
2. **准备应用制品或模板**：将业务容器镜像推送至镜像仓库，并将打包好的 **Helm Chart** 上传至项目专属 Chart 仓库（或在控制台编写 **模板文件 / K8S 资源配置**）。
3. **部署与运维应用**：使用 Helm Release、模板文件或资源视图将应用下发至目标集群的指定命名空间，通过平台内置的容器监控、日志采集、事件查询和 WebConsole 进行日常运维。

## 核心优势

### 1. 原生 Kubernetes 支持与多云异构纳管

- **100% 兼容原生 K8S**：基于社区原生 Kubernetes 实现，全面支持标准 K8S 工作负载、网络、存储、RBAC 及 CRD 生态，支持通过原生 `kubectl` 和 Kubernetes API 直接访问集群。
- **多云与混合云统一管理**：
  - 支持在私有化环境一键自建高可用 K8S 原生集群。
  - 支持新建或导入主流公有云容器集群（腾讯云 TKE、谷歌云 GKE、亚马逊云 EKS、微软云 AKS、华为云 CCE 等）。
  - 支持通过 Kubeconfig 接入任意兼容社区标准的外部 K8S 集群。
  - 支持跨云区域（通过 Proxy 代理）及 `x86_64` / `arm64` 多架构异构集群混合纳管，降低单一云厂商锁定风险。

### 2. 深度融合蓝鲸研运生态

- **配置平台（CMDB）联动**：项目与 CMDB 业务绑定，直接复用 CMDB 主机资源池进行建群与扩缩节点，并支持通过 `bcs-bkcmdb-synchronizer` 将容器拓扑数据实时同步回 CMDB。
- **权限中心（IAM）统一鉴权**：支持项目、集群、命名空间、模板集等细粒度 RBAC 与蓝鲸 IAM 权限管控。
- **标准运维（SOPS）与节点管理（Nodeman）协同**：集群初始化、节点上下架、GSE Agent 安装与自动化流程深度集成。
- **开箱即用的监控与日志**：无缝对接蓝鲸监控平台（`bkmonitor-operator`）与蓝鲸日志平台（`bcs-log-collector` / `bk-log`），提供集群、节点、Pod、容器多维度的指标告警与标准输出/文本日志采集。

### 3. 面向复杂业务与游戏场景的云原生扩展

针对游戏服（GameServer）及大型有状态/长连接微服务的痛点，BCS 提供了自研的增强型 Operator 组件库：

- **增强型工作负载（`GameDeployment` / `GameStatefulSet`）**：支持容器**原地重启升级（InplaceUpdate）**、**镜像热更新（HotPatchUpdate）**、**自动并行更新**、**失联节点 Pod 自动漂移**、**指定 Pod 缩容**、**Pod 唯一序号注入**及**防误删保护**。
- **精细化发布钩子（`bcs-hook-operator`）**：提供 `HookTemplate` 与 `HookRun`，支持在实例删除/原地更新前后或分步灰度（Canary）过程中执行 Webhook、Prometheus 指标或 K8S 资源校验，实现无损优雅发布与游戏对局保护。
- **通用弹性伸缩（`GeneralPodAutoscaler`，GPA）**：在兼容原生 HPA 指标伸缩的基础上，扩展支持 **Crontab 定时伸缩**、**Webhook 自定义策略伸缩**、**外部事件驱动伸缩**及多模式混合伸缩。
- **高性能网络接入（`bcs-ingress-controller`）**：支持对接腾讯云 CLB、AWS ALB/NLB、GKE 负载均衡，提供 NodePort 转发、CLB 直通 Pod、StatefulSet 端口段映射、**PortPool 动态端口池分配**、随机 HostPort 注入及跨地域绑定能力。

### 4. 权威认证与适用场景

蓝鲸智云容器管理平台已通过中国**云计算开源产业联盟**组织的**可信云容器解决方案评估认证**，广泛适用于以下企业级场景：

- **微服务架构治理与云原生转型**
- **游戏服务器（开服、合服、灰度原地更新、长连接直通）编排管理**
- **开发测试环境快速供给与共享集群资源复用**
- **持续集成与持续交付（CI/CD）流水线底座**
- **跨云、跨地域、多架构集群统一运维自动化**
