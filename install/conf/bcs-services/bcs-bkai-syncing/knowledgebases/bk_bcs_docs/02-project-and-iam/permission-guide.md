# 权限管理指南

蓝鲸容器管理平台（BCS）全面对接**蓝鲸权限中心（IAM）**，采用基于角色的访问控制与细粒度资源实例授权模型，确保多团队、多集群环境下的安全隔离。

---

## 一、BCS 权限模型概览

BCS 在蓝鲸权限中心中的系统标识为 `bk_bcs_app`，权限按资源层级从高到低分为以下几类：

| 资源层级 | 权限操作名称 | 权限说明 | 适用角色 |
| :--- | :--- | :--- | :--- |
| **平台级** | `项目创建` | 允许在 BCS 平台创建新项目 | 项目负责人、运维负责人 |
| **项目级** | `项目查看` | 允许进入指定项目，查看项目基本信息、事件查询、操作记录等 | 项目所有成员（基础必选权限） |
| **项目级** | `项目编辑` | 允许修改项目信息、关联/变更 CMDB 业务 | 项目管理员、业务运维 |
| **云凭证级** | `云账号创建` / `云账号管理` / `云账号使用` | 允许在项目中新建、删除、在建群时选用公有云凭证 | 云基础设施管理员 |
| **集群级** | `集群创建` | 允许在项目下新建集群或导入外部集群 | 集群管理员、业务运维 |
| **集群级** | `集群查看` | 允许查看集群列表、集群详情、节点列表及集群监控状态 | 开发人员、测试人员、运维人员 |
| **集群级** | `集群管理` | 允许修改集群配置、添加/删除节点、管理节点池、开启弹性伸缩、启用插件等 | 集群管理员、SRE |
| **集群级** | `集群删除` | 允许删除或下架集群（高危操作） | 集群管理员 |
| **集群级** | `集群资源查看` / `集群资源管理` | 允许查看或管理集群级（非命名空间作用域）K8S 资源（如 PV、StorageClass、CRD 等） | 集群管理员、高级研发 |
| **命名空间级** | `命名空间创建` | 允许在指定集群下创建新命名空间 | 环境管理员、研发负责人 |
| **命名空间级** | `命名空间查看` / `命名空间管理` / `命名空间删除` | 允许查看、修改配额/变量或删除指定命名空间 | 模块负责人、运维 |
| **命名空间资源级** | `命名空间下资源查看` | 允许查看指定命名空间下的 Workload、Pod、Service、Ingress、ConfigMap、Secret、Helm Release 等（只读） | 普通研发、测试、排障人员 |
| **命名空间资源级** | `命名空间下资源管理` | 允许在指定命名空间下创建、更新、扩缩容、删除 K8S 资源与 Helm Release，以及进入 Pod WebConsole（读写） | 应用开发者、发布负责人 |
| **模板集级** | `模板集创建` / `查看` / `编辑` / `删除` / `实例化` | 允许管理部署管理中的模板集与模板文件并下发实例 | 应用开发者、运维 |

## 二、常见角色权限申请推荐方案

在日常协作中，建议按人员职责在蓝鲸权限中心申请对应权限组合：

### 1. 只读观察者 / 测试人员（仅查看状态与日志）
- **必选权限**：目标项目的 `项目查看` + 目标集群的 `集群查看` + 目标命名空间的 `命名空间查看` 与 `命名空间下资源查看`。
- **效果**：可在控制台浏览资源视图、查看 Pod 状态与容器标准输出日志、查询项目/集群/发布状态，但无法修改任何资源或进入 WebConsole。

### 2. 应用开发人员（日常发版、配置修改与排障）
- **必选权限**：
  - 项目级：`项目查看`
  - 集群级：`集群查看`
  - 命名空间级：负责业务所在命名空间的 `命名空间查看` + `命名空间下资源查看` + `命名空间下资源管理`
- **效果**：可在指定命名空间下部署和更新 Helm Release、修改 Deployment/ConfigMap/Service、重启 Pod，以及使用 WebConsole 进入自己有权限的 Pod 容器调试，同时与其他命名空间隔离。

### 3. 集群管理员 / 业务运维（全集群管控）
- **必选权限**：
  - 项目级：`项目查看`、`项目编辑`、`云账号管理`
  - 集群级：`集群创建`、`集群查看`、`集群管理`、`集群资源查看`、`集群资源管理`
  - 命名空间级：勾选全量命名空间的 `命名空间查看`、`命名空间管理`、`命名空间下资源管理`
  - **额外要求**：若需新建集群或从 CMDB 添加主机节点，还需在**蓝鲸配置平台（CMDB）**对应业务中具备 `业务运维` 角色（或目标主机的主/备负责人权限）。

## 三、如何申请权限

### 方式 1：在 BCS 控制台触发快捷申请
当您在 BCS 页面点击未授权的项目、集群、命名空间或操作按钮（如【创建】、【更新】、【WebConsole】）时，页面会自动弹出**无权限提示弹窗**：
1. 弹窗中会明确列出当前操作所缺失的具体权限名称及关联资源实例。
2. 点击弹窗中的【去申请】按钮，系统将自动跳转至蓝鲸权限中心并预填好所需权限项。
3. 填写申请理由与有效期，点击【提交】等待审批即可。

### 方式 2：在蓝鲸权限中心主动申请
1. 登录**蓝鲸权限中心（IAM）**，点击【权限申请】→【申请自定义权限】。
2. 在系统列表中选择**容器管理平台（`bk_bcs_app`）**。
3. 勾选需要申请的操作权限（如 `项目查看`、`集群查看`、`命名空间下资源管理`）。
4. 在右侧**关联资源实例**中选择对应的项目、集群或命名空间：
   - 若需申请整个项目下所有集群/命名空间的权限，可开启【批量编辑】或直接选择项目级无限制范围。
   - 若只需申请特定命名空间权限，按 `项目 -> 集群 -> 命名空间` 层级精确勾选。
5. 选择申请期限（临时或永久），提交审批。

## 四、Kubeconfig 与 API 调用的权限说明

- 用户在 BCS 平台创建的 **API 密钥（User Token）** 或导出的 **Kubeconfig**，其权限与该用户在**蓝鲸权限中心（IAM）**中所拥有的 BCS 权限完全一致。
- 当使用 `kubectl` 或调用 `https://{bcs-api-gateway}/clusters/{cluster_id}/...` 接口时，BCS 网关与 `bcs-user-manager` 会实时向蓝鲸权限中心校验该用户在目标集群或命名空间下是否具备 `集群资源查看/管理` 或 `命名空间下资源查看/管理` 权限。
- 若使用 `kubectl` 时遇到 `Forbidden` 报错，请检查当前账号在蓝鲸权限中心是否已申请并通过了对应集群及命名空间的权限审批。
