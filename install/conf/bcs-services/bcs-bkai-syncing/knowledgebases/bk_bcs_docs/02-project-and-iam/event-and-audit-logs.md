# 事件查询与操作审计记录

为了帮助用户快速定位集群异常与回溯变更历史，蓝鲸容器管理平台（BCS）在【项目管理】模块下提供了**事件查询**与**操作记录**两大审计排障工具。

---

## 一、事件查询（Event Query）

原生 Kubernetes 集群中的 Event 默认仅在 Etcd 中保留较短时间（通常为 1 小时），过期后即被清理，导致事后排查 Pod 重启、调度失败或镜像拉取异常时缺乏依据。
BCS 会通过采集组件实时收集项目下所有纳管集群的 K8S 事件并**持久化存储**，支持按多维度检索历史事件。

### 1. 前提条件

- 已登录蓝鲸平台，并拥有目标项目的**项目查看**权限。

### 2. 查询入口与筛选条件

进入【项目管理】→【事件查询】，支持以下组合条件过滤：

| 筛选维度 | 说明与可选值 |
| :--- | :--- |
| **集群** | 选择项目下的特定集群（必选或切换集群） |
| **命名空间** | 选择特定命名空间，或跨命名空间查询全集群事件 |
| **日期时间范围** | 通过时间选择器框定故障发生的时间窗口 |
| **组件（Component）** | 按触发事件的 K8S 组件筛选（如 `kubelet`、`default-scheduler`、`deployment-controller` 等） |
| **资源类型（Kind）** | 按事件涉及的资源类型筛选（如 `Pod`、`Node`、`Deployment`、`StatefulSet`、`PersistentVolumeClaim` 等） |
| **事件级别（Level）** | 按严重程度筛选：`Normal`（正常事件）、`Warning`（告警/异常事件，排障时重点关注） |
| **资源名称** | 输入具体 Pod 名称或工作负载名称关键字进行搜索 |

### 3. 查询结果字段说明

查询结果按时间倒序分页展示：

- **时间**：事件产生的时间戳。
- **组件**：上报该事件的控制器或节点组件名称。
- **资源名称 / 类型**：关联的具体 K8S 资源对象。
- **事件级别**：`Normal` 或 `Warning`。
- **事件内容（Message）**：事件的详细原因描述（例如 `FailedScheduling: 0/5 nodes are available: Insufficient cpu` 或 `Back-off pulling image "..."`）。

---

## 二、操作记录（Operation Audit Logs）

操作记录功能用于追踪用户在当前项目中发起的所有变更操作及其执行结果，便于团队变更审计与故障回溯。

### 1. 前提条件

- 已登录蓝鲸平台，并拥有目标项目的**项目查看**权限。

### 2. 筛选条件

进入【项目管理】→【操作记录】，支持按以下条件组合查询：

- **操作对象类型（Resource Type）**：
  - `全部`、`项目`、`集群`、`节点`、`节点池`、`云账号`、`命名空间`、`模板集`、`变量`、`K8S资源`、`Helm`、`集群组件`、`Chart`、`Webconsole`、`日志采集规则`。
- **操作类型（Activity Type）**：
  - `全部`、`创建/新增`、`更新`、`删除`、`开始`、`停止`。
- **操作状态（Status）**：
  - `全部`、`成功`、`失败`、`处理中`、`未知`。
- **日期范围**：指定变更发生的时间区间。
- **操作人**：按发起操作的用户名过滤。

### 3. 查询结果字段说明

- **时间**：操作发起的时间。
- **操作类型**：执行的动作（创建、更新、删除等）。
- **对象类型**：被操作的资源分类。
- **状态**：操作的最终执行状态（成功/失败/处理中）。
- **发起者**：执行该操作的用户账号。
- **描述**：操作的详细摘要（如变更的具体集群 ID、Release 名称或节点 IP）。
