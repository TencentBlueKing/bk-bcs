# 项目管理指南

项目（Project）是蓝鲸容器管理平台（BCS）的一级管理入口，所有集群、部署模板、Helm 仓库、变量和云凭证均围绕项目进行组织与权限隔离。

---

## 一、创建项目

### 1. 前提条件

- 已登录蓝鲸平台。
- 当前用户在蓝鲸权限中心（IAM）已被授予容器管理平台（`bk_bcs_app`）的**项目创建**权限。

### 2. 创建入口

- **无任何项目权限时**：首次进入 BCS 平台将展示欢迎页，直接点击页面中央的【创建项目】按钮。
- **已有其他项目权限时**：点击顶部导航栏左侧的**项目选择器**下拉框，点击底部的【项目管理】进入项目管理页，再点击【创建项目】按钮。

### 3. 填写项目基本信息

| 字段名称 | 填写要求与格式限制 | 说明 |
| :--- | :--- | :--- |
| **项目名称** (`name`) | 长度为 2~64 个字符，支持中文、英文、数字及特殊字符（空格、下划线等） | 项目的可读显示名称 |
| **项目英文名** (`projectCode`) | 长度为 2~32 个字符，**仅允许小写字母、数字和中划线 `-`**，且**必须以小写字母开头** | 项目全局唯一英文代号，创建后不可修改，常用于 URL 路径、Helm 仓库名及 API 调用 |
| **项目说明** (`description`) | 文本描述 | 说明项目背景、归属团队及业务目标 |

填写完成后点击【确认】，系统将创建新项目，并自动为创建人授予该项目的**项目查看**和**项目编辑**权限。

---

## 二、启用容器服务（绑定 CMDB 业务）

新建项目后，需绑定蓝鲸配置平台（CMDB）业务以启用完整的容器管理能力。

### 1. 前提条件

- 当前用户拥有该 BCS 项目的**项目查看**与**项目编辑**权限。
- 当前用户在拟关联的 **CMDB 业务**中拥有**业务运维**角色（系统仅允许绑定当前用户具备业务运维权限的 CMDB 业务）。

### 2. 绑定说明与注意事项

1. 进入目标项目后，在引导页或【项目管理】→【项目信息】中选择要关联的 CMDB 业务并保存。
2. **为什么必须绑定 CMDB 业务？**
   - 在创建 K8S 原生集群、独立集群或向集群添加已有服务器节点时，BCS 会从所绑定的 CMDB 业务主机资源池（空闲机模块）拉取可选服务器列表。
   - 节点上下架时，BCS 会自动在 CMDB 对应业务拓扑模块中进行主机转移。
   - 容器拓扑同步（`bcs-bkcmdb-synchronizer`）、蓝鲸监控与日志采集的数据归属均依赖该 CMDB 业务 ID（`businessID` / `bk_biz_id`）。
3. **重要提示（TKE 集群拓扑限制）**：
   - 蓝鲸内置的“蓝鲸”系统业务默认不支持自定义容器主机拓扑。如果需要新建腾讯云 TKE 集群并自动转移节点模块，请确保 BCS 项目绑定的是**非蓝鲸内置业务**，并在该 CMDB 业务下提前创建好业务拓扑模块。

---

## 三、加入已存在的项目

在项目管理页面或顶部项目选择器中，默认可浏览平台上的项目列表。若当前用户尚未拥有某项目的访问权限：

- 点击该项目名称时，系统将弹出无权限提示，引导申请该项目的**项目查看**权限。
- 点击【编辑项目】操作时，系统将引导申请该项目的**项目编辑**权限。
- 提交权限申请并通过项目管理员审批后，刷新页面即可进入项目。

---

## 四、项目信息与项目配额管理

### 1. 查看与编辑项目信息

进入【项目管理】→【项目信息】，可以查看项目的以下核心元数据（这些信息也是调用 BCS API 时的常用参数）：

- **项目名称**（`name`）
- **项目英文名**（`projectCode`）
- **项目 ID**（`projectID`，32 位 UUID 字符串）
- **关联 CMDB 业务**（`businessID` / `businessName`）
- **创建时间与创建人**

### 2. 项目配额（Project Quotas）

当项目使用平台提供的**共享集群**或联邦算力资源时，可在【项目管理】→【项目配额】中查看当前项目获批的 CPU、内存、存储等资源配额总量及实时使用率，辅助团队进行容量规划。
