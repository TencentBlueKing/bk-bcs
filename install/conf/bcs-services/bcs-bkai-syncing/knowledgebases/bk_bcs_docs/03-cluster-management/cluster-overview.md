# 集群管理概述与纳管能力矩阵

蓝鲸容器管理平台（BCS）在【集群管理】模块中提供了统一的集群生命周期管理入口，支持**新建集群**与**导入外部集群**两大模式，覆盖私有化自建环境、多云公有云环境、跨云区域及多 CPU 架构（`x86_64` / `arm64`）异构环境。

---

## 一、集群管理核心功能

1. **新建集群**：
   - **K8S 原生集群（私有化自建）**：利用项目关联 CMDB 业务下的空闲主机，通过标准运维自动化流程一键部署高可用 Kubernetes 集群。
   - **公有云集群**：对接腾讯云 TKE、亚马逊云 EKS、谷歌云 GKE、微软云 AKS 等云厂商 API 直接创建托管或独立集群。
   - **虚拟集群（vCluster）与联邦集群（Clusternet）**：支持在共享集群之上划分虚拟子集群，或构建多集群联邦。
2. **导入外部集群**：
   - **通过云凭证导入**：接入腾讯云、谷歌云、亚马逊云、微软云、华为云已有容器集群。
   - **通过 Kubeconfig 导入**：接入任意兼容社区原生 Kubernetes 标准的存量集群。
3. **集群节点与容量管理**：
   - 节点扩容（已有服务器上架或节点池扩容）、节点缩容下架、停止调度（Cordon）、Pod 驱逐（Drain）、标签与污点批量管理、节点模板管理。
   - 基于 `Cluster Autoscaler` 的节点池自动弹性伸缩。
4. **集群健康与监控视图**：
   - 实时展示集群状态、Master 控制面信息、网络配置（VPC、CIDR、网络插件）及集群 CPU/内存/磁盘资源水位。

## 二、集群接入方式对比（选型参考）

在将集群接入 BCS 时，可根据基础设施环境与管控深度诉求选择最合适的方式：

| 对比维度 | 新建 K8S 原生集群 | 新建公有云集群（如 TKE） | 通过云凭证导入集群 | 通过 Kubeconfig 导入集群 |
| :--- | :--- | :--- | :--- | :--- |
| **适用场景** | 私有化机房、无公有云环境 | 公有云全新业务建群 | 纳管公有云上已创建的存量集群 | 纳管任意第三方云、自建或受限环境的 K8S 集群 |
| **支持云厂商/平台** | 蓝鲸私有化环境（Linux 主机） | 腾讯云 TKE、AWS EKS、GCP GKE、Azure AKS | 腾讯云、谷歌云、AWS、Azure、华为云 | 任意兼容原生 K8S 的集群 |
| **K8S 集群内资源管理** | 支持 | 支持 | 支持 | 支持 |
| **添加/删除集群节点** | 支持（从 CMDB 主机池选择） | 支持（主机池或节点池） | **支持**（联动云厂商 API） | **不支持**（需在原集群侧扩缩节点） |
| **节点池与自动扩缩容 (CA)** | 支持（内部节点池） | 支持 | **支持** | **不支持** |
| **云负载均衡联动** | 需额外部署网关/LB | 支持 | **支持** | 仅支持集群内资源级别配置 |
| **前置要求** | CMDB 空闲主机 + GSE Agent + 标准运维流程 | 云凭证（含创建与支付权限）+ CMDB 非蓝鲸业务拓扑 | 云凭证（含集群访问权限）+ 开启集群 APIServer 访问 | 集群有效 Kubeconfig（或最小 RBAC 授权） |

## 三、BCS 集群 ID 与云厂商集群 ID 映射关系

在公有云集群（以腾讯云 TKE 为例）创建或导入后，平台存在两套标识字段。日常运维与排查时请注意区分：

| 平台 | 字段名称 | 字段标识 | 是否可变 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **BCS** | 集群 ID | `clusterID` | **否** | `BCS-K8S-40009` | BCS 系统自动生成的全局唯一标识（API、监控、Kubeconfig 均使用此 ID） |
| **BCS** | 集群名称 | `clusterName` | 是 | `广州-生产集群-01` | BCS 控制台展示的集群名称，支持用户修改 |
| **BCS** | 云集群 ID | `systemID` | **否** | `cls-72b5p8ho` | 记录底层云服务商分配的集群唯一 ID |
| **TKE** | 集群 ID | `ClusterId` | **否** | `cls-72b5p8ho` | 腾讯云 TKE 控制台生成的集群唯一标识 |
| **TKE** | 集群名称 | `ClusterName` | 是 | `BCS-K8S-40009` 或自定义 | TKE 侧集群名称（BCS 新建时默认命名为 `clusterID`，但两侧均可独立修改） |

> **关键结论**：
> - **唯一关联依据**：BCS 集群详情中的 **`systemID`（TKE 集群 ID）** 与云厂商控制台的**集群 ID（如 `cls-xxxx`）**完全一致且不可修改，是核对两侧集群一一对应关系的唯一准确依据。
> - **命名建议**：建议在 BCS 中采用 `「地域-环境/用途-序号」`（如 `广州-测试集群-01`）进行规范化命名，便于团队直观识别。
