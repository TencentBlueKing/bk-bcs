# 集群节点管理与节点模板

通过蓝鲸容器管理平台（BCS）的【集群管理】→【节点列表】与【节点模板】，用户可以对集群计算节点（Worker Nodes）进行扩容添加、日常调度控制、标签/污点批量管理以及安全下架。

> **注意**：通过 **Kubeconfig** 方式导入的外部集群仅管控集群内 K8S 资源，不支持在 BCS 控制台直接执行“添加节点”或“删除主机”操作（但仍支持停止调度、Pod 驱逐、设置标签和污点）。

---

## 一、添加集群节点

### 1. 前提条件
- 当前用户在蓝鲸权限中心具备对应项目的**项目查看**，以及目标集群的**集群查看**和**集群管理**权限。
- 若从 CMDB 已有服务器添加节点，用户需在项目关联的 CMDB 业务中担任**业务运维**角色（或为所选服务器的主/备负责人），且目标服务器已安装蓝鲸 GSE Agent 且处于正常状态。

### 2. 添加节点方式

进入【集群管理】→ 点击目标集群的【节点列表】→ 点击【添加节点】：

#### 方式 A：使用已有服务器（适用于自建 K8S 原生集群及公有云集群）
1. **选择节点**：从项目关联的 CMDB 业务主机拓扑（空闲机池）中勾选待加入集群的服务器。
2. **选择节点模板（可选）**：应用预设的节点初始化参数、标签（Labels）、污点（Taints）及初始化脚本。
3. **配置登录方式（公有云如 TKE 集群）**：
   - **密码登录**：设置节点 root 密码。
   - **SSH 密钥登录**：选择公钥并配置私钥（公钥写入 `~/.ssh/authorized_keys`，私钥用于安装 GSE Agent）。
4. **确认提交**：点击【确认】启动节点初始化与上架流程。可在节点列表中实时查看状态与任务日志；若上架失败，支持点击【重试】或直接销毁失败记录。

#### 方式 B：从节点池添加（适用于已配置节点池的云集群）
1. 选择目标**节点池（NodePool）**。
2. 输入**添加节点数量**（受节点池最大配额限制），点击【确认】触发云厂商自动扩容并加入集群。

## 二、节点日常运维操作

在【集群管理】→【节点列表】中，支持对单个或多个节点批量执行以下运维操作：

| 操作名称 | 对应 `kubectl` 语义 | 操作说明与注意事项 |
| :--- | :--- | :--- |
| **停止调度** | `kubectl cordon <node>` | 将节点标记为不可调度（`SchedulingDisabled`）。新创建的 Pod 不会再调度到该节点，但节点上已运行的 Pod 不受影响。**在对节点进行维护、重启、Pod 驱逐或删除节点前，必须先执行停止调度。** |
| **允许调度** | `kubectl uncordon <node>` | 恢复节点的正常调度状态，允许新 Pod 调度至该节点。 |
| **Pod 驱逐** | `kubectl drain <node>` | 将该节点上运行的业务 Pod 优雅驱逐并重新调度到集群内其他可用节点（DaemonSet 管理的 Pod 除外）。常用于节点停机维护或下架前清空负载。 |
| **设置标签（Labels）** | `kubectl label node ...` | 支持单个或批量为节点添加/修改/删除自定义 `Key=Value` 标签，结合 Pod 的 `nodeSelector` 或 `nodeAffinity` 实现定向调度。 |
| **设置污点（Taints）** | `kubectl taint node ...` | 支持为节点配置污点（Effect 支持 `NoSchedule`、`PreferNoSchedule`、`NoExecute`），防止未配置对应容忍度（`tolerations`）的普通 Pod 调度到专用节点（如 GPU 节点、大内存节点）。 |
| **删除节点** | `kubectl delete node` + 下架 | **仅在节点处于“停止调度”状态后才允许删除**。建议标准下架流程：`停止调度 -> Pod 驱逐 -> 确认业务 Pod 清空 -> 删除节点`。 |

## 三、节点模板管理（Node Template）

当需要频繁扩容具有相同特征（如统一打上业务模块标签、专用污点、调整内核参数或安装特定依赖）的节点时，可在【集群管理】→【节点模板】中提前创建模板：

- **预设标签与污点**：定义节点加入集群时自动携带的 Kubernetes Labels 与 Taints。
- **Kubelet 与容器运行时参数**：自定义节点级组件启动参数。
- **前置/后置初始化脚本（Pre/Post Actions）**：支持配置节点加入集群前后自动执行的 Shell 脚本或标准运维流程，实现节点标准化交付。
