# 新建公有云集群（以腾讯云 TKE 为例）

蓝鲸容器管理平台（BCS）支持通过云厂商 API 直接新建公有云 Kubernetes 集群（包括腾讯云 TKE、谷歌云 GKE、亚马逊云 EKS、微软云 AKS 等），并自动完成 CMDB 主机模块转移、GSE Agent 安装与 BCS 组件接入。

---

## 一、前提条件与关键配置（必读）

### 1. 权限与云凭证准备
- 当前用户在蓝鲸权限中心具备目标项目的**项目查看**和**集群创建**权限。
- 当前用户在项目绑定的 CMDB 业务中具备**业务运维**角色。
- 已在【项目管理】→【云凭证】中配置好对应公有云的访问凭证（如腾讯云 `SecretID` 和 `SecretKey`）。

### 2. 关键前置条件：CMDB 业务拓扑与项目绑定
在新建腾讯云 TKE 集群时，第四步“节点配置”需要将新创建的节点转移至 CMDB 业务拓扑模块。请务必满足以下要求：

1. **禁止绑定内置“蓝鲸”业务**：CMDB 中的内置“蓝鲸”业务默认不支持自定义业务拓扑，若 BCS 项目绑定的是“蓝鲸”业务，建群时将无法选择节点转移模块。
2. **在非蓝鲸业务下提前创建拓扑模块**：
   - 登录蓝鲸配置平台（CMDB）→ 选择目标业务（非蓝鲸业务）→【业务拓扑】→ 提前创建好用于存放容器节点的集群（Set）与模块（Module）。
   - 确保 BCS 项目绑定的是该非蓝鲸业务。

---

## 二、新建腾讯云 TKE 集群四步流程

操作路径：顶部导航栏【集群管理】→【添加集群】→【新建集群】→【公有云集群】→ 选择【腾讯云】。

### 第一步：填写基本信息
- **基本信息**：
  - **云凭证**：选择已配置的腾讯云凭证。
  - **云项目**：选择关联的腾讯云项目。
  - **集群名称**：填写 1~64 字符的集群名称。
  - **集群版本**：选择当前 TKE 支持的 Kubernetes 版本。
  - **标签与描述**（可选）：设置集群标签与说明。
- **集群环境**：
  - **所属区域**：选择腾讯云地域（如广州、上海、南京等）。
  - **管控区域**：选择蓝鲸 GSE Agent 对应的管控区域（云区域）。
  - **集群环境**：选择`测试`或`正式`。
- **集群配置**：
  - **操作系统**：选择 TKE 支持的节点操作系统镜像。
  - **运行时组件与版本**：选择 `containerd` 或 `docker` 及其对应版本。

### 第二步：填写网络配置
- **基本配置**：
  - **私有网络（VPC）**：选择集群所在地域的腾讯云 VPC 及子网。
  - **默认网络插件**：
    - `GlobalRouter`（TKE 基于 VPC 全局路由的 Overlay 网络）：需指定**容器网段 CIDR**、**Service IP 数量**（128~4096）及**单节点 Pod 数量上限**（32/64/128）。
    - `VPC-CNI`（Underlay 弹性网卡直通网络）：需指定 **Service CIDR**、各可用区 **Pod IP 子网**，以及是否开启**固定 Pod IP**。
  - **集群 IP 类型**：目前默认 IPv4。

### 第三步：填写控制面配置
- **集群模式**：
  - **托管集群（推荐）**：Master 控制面与 Etcd 由腾讯云 TKE 团队集中托管维护，用户无需关心 Master 节点运维。需选择**集群规格**（支持自动升级）及 **APIServer CLB 访问方式**（公网访问需配置安全组放通，内网访问需确保 BCS 与 TKE VPC 内网互通）。
  - **独立集群**：使用用户自购或已有 CVM 作为 Master 节点（仅支持 3 台或 5 台），需配置节点规格、安全组、CMDB 控制面节点转移模块及 SSH 登录方式。

### 第四步：填写节点配置并创建
- **节点资源**：支持新申请 CVM 节点（配置计费模式、机型规格、数据盘、安全组）或从 CMDB 业务主机拓扑中选择已有 CVM 服务器。
- **节点转移模块**：选择前置步骤在 CMDB 业务拓扑中创建好的目标模块。
- **登录方式**：设置 root 密码或 SSH 密钥（用于初始化及安装 GSE Agent）。
- **确认创建**：核对配置无误后点击【确定】，系统将触发异步建群任务，可通过集群列表【查看日志】跟踪进度。

## 三、新建与纳管 TKE 集群常见报错排查

### 1. 腾讯云 CAM 权限相关错误

若建群或纳管日志提示 `UnauthorizedOperation`，说明云凭证对应的腾讯云账号缺少权限：

- **快速全量授权方案（推荐）**：在腾讯云【访问管理 CAM】中为该账号直接绑定以下两个预设策略：
  - `QcloudTKEFullAccess`：TKE 集群全读写权限（创建集群、开启端点、获取 RBAC 授权等）。
  - `QCloudFinanceFullAccess`：云资源支付/扣费校验权限（新建集群或购买节点时必需）。

- **按报错信息精准提权对照表**：

| 报错关键词 | 缺失权限原因 | 解决方案 |
| :--- | :--- | :--- |
| `tke:CreateCluster` | 缺少 TKE 集群创建权限 | 在 CAM 中为账号添加 `tke:CreateCluster` 权限 |
| `CVM_COMMON_ERROR[UnauthorizedOperation:无支付权限]` | 缺少云资源扣费/支付校验权限 | 必须为账号绑定 `QCloudFinanceFullAccess` 策略 |
| `tke:CreateClusterEndpoint` | 缺少开启集群 APIServer 访问端点权限 | 添加 `tke:CreateClusterEndpoint` 权限 |
| `tke:AcquireClusterAdminRole` | 缺少获取集群 Admin 角色权限 | 添加 `tke:AcquireClusterAdminRole` 权限 |
| `same type task in execution`（Endpoint 相关） | **非权限问题**，TKE 侧存在未完成的同类型端点任务 | 无需提权，等待 5~10 分钟待 TKE 侧端点任务结束后重试即可 |

### 2. 安装 GSE Agent 失败或主机模块转移失败

#### 问题 A：建群/纳管任务中“安装 GSE Agent”步骤失败
- **原因**：蓝鲸节点管理服务与 TKE 节点之间网络不通（如跨 VPC 未打通、防火墙拦截），导致无法自动安装 GSE Agent。
- **解决**：若暂不需要通过蓝鲸对底层节点执行脚本运维，可在任务日志弹窗中直接点击【跳过】继续完成集群纳管；后续打通网络后再补装 GSE Agent。

#### 问题 B：报错 `transfer host module failed [GetBS2IDByBizID failed]`
- **原因**：跳过 GSE Agent 安装或导入外部 TKE 集群时，蓝鲸 CMDB 中尚未录入该 TKE 节点的 IP 信息，导致 BCS 无法在 CMDB 中将节点转移至目标业务模块。
- **解决步骤**：
  1. 登录腾讯云 TKE 控制台 →【节点管理】，复制所有节点的**内网 IP**。
  2. 登录蓝鲸【配置平台（CMDB）】→【主机管理】→ 手动录入这些节点 IP。
  3. 在 CMDB 中将录入的节点转移至当前 BCS 项目所关联业务的**空闲机池**。
  4. 回到 BCS 集群管理页面重新执行重试操作即可成功。
