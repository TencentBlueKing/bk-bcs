# v1.31.0 Changelog
### Feature
- [Feature] `Common` Support *multi-tenant* deployment and multi-tenant capabilities
- [Feature] `Common` Support deployment under a *sub-path*
- [Feature] `Cluster Management` Support creating clusters and adding nodes with *custom images*
- [Feature] `Cluster Management` Adding nodes to native clusters and via auto-scaling (CA) supports pre-run *Standard Ops (SOPS)* workflows
- [Feature] `Cluster Management` Shared clusters support customizable approval configuration
- [Feature] `Cluster Management` Support configuring cluster *audit logs*
- [Feature] `Cluster Management` Support manually adding/removing *GPU nodes*, and auto-scaling (CA) supports GPU node pools
- [Feature] `Cluster Management` Tencent Cloud public clusters support *IPv6*
- [Feature] `Cluster Management` Support node annotations and copying cluster kubeconfig; cluster tasks can be skipped or retried
- [Feature] `Deploy Management` Template files support *sub-folders* and deploying multiple selected template files
- [Feature] `Deploy Management` Template file deployment supports *diff preview*, and Helm deployment adds *native mode*
- [Feature] `Dashboard` CRD list supports all *APIResources*, and CRD details show the Pod list of specific resources
- [Feature] `Dashboard` Support *namespace grouping*
- [Feature] `Dashboard` Resource details page supports *scaling* and opening in a new page
- [Feature] `Dashboard` Pod monitoring supports switching between *CPU Request/Limit usage* and *CPU peak usage*
- [Feature] `Namespace` Namespace quotas support adjusting Request/Limit and managing multiple resource quotas, with *Pod LimitRange* management
- [Feature] `Data Sync` CMDB container data supports syncing *CRD* resources
### Improved
- [Improved] `Common` Upgraded Golang to 1.27 and Node.js to 24
- [Improved] `Cluster Management` Improved prompts for cluster creation, node addition and related operations
- [Improved] `Cluster Management` Updated the supported Kubernetes cluster versions
- [Improved] `Cluster Management` Improved node Pod eviction with eviction preview, showing DaemonSet and PDB non-evictable Pods separately
- [Improved] `Cluster Management` Multiple feature and stability improvements for *Amazon EKS*, *Google GKE* and *Azure AKS* node pools
- [Improved] `Cluster Management` Retry for partially failed node add/remove operations and improved task logs
- [Improved] `Dashboard` Remembers column widths and the last selected namespace; Pod details embed event query from the monitoring platform
- [Improved] `Quota Management` Redesigned the quota management page
- [Improved] `WebConsole` Support entering initContainers and Windows copy shortcuts
- [Improved] `Security` Fixed multiple XSS risks and upgraded frontend dependencies
