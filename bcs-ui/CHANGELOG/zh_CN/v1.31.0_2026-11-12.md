# v1.31.0 版本更新日志
### 新增
- [新增] `公共` 支持*多租户*模式部署并提供多租户能力
- [新增] `公共` 支持*子路径*模式部署
- [新增] `集群管理` 支持使用*自定义镜像*创建集群和上架节点
- [新增] `集群管理` 原生集群上架节点和弹性伸缩（CA）上架节点支持前置*标准运维*流程
- [新增] `集群管理` 共享集群支持自定义配置审批
- [新增] `集群管理` 支持配置集群*审计日志*
- [新增] `集群管理` 支持 *GPU 节点*手动上下架，弹性伸缩（CA）支持 GPU 节点池
- [新增] `集群管理` 腾讯云公有云集群支持 *IPv6*
- [新增] `集群管理` 支持节点设置注解、复制集群 kubeconfig，集群任务支持跳过和重试
- [新增] `部署管理` 模板文件支持*子文件夹*及多选模板文件部署
- [新增] `部署管理` 模板文件部署前支持*预览差异（diff）*，Helm 部署新增*原生模式*
- [新增] `资源视图` CRD 列表支持所有 *APIResources*，CRD 详情支持展示特定资源下的 Pod 列表
- [新增] `资源视图` 支持*命名空间分组*
- [新增] `资源视图` 资源详情页支持*扩缩容*操作及在新页面打开
- [新增] `资源视图` Pod 监控支持切换 *CPU Request/Limit 使用率*及 *CPU 峰值使用率*
- [新增] `命名空间` 命名空间配额支持调整 Request/Limit 及管理多种资源配额，支持 *Pod LimitRange* 管理
- [新增] `数据同步` CMDB 容器数据支持同步 *CRD* 资源
### 优化
- [优化] `公共` Golang 升级至 1.27，Node.js 升级至 24
- [优化] `集群管理` 创建集群、上架节点等提示信息优化
- [优化] `集群管理` 可管理的 Kubernetes 集群版本更新
- [优化] `集群管理` 节点 Pod 驱逐优化，支持驱逐预览并区分展示 DaemonSet 与 PDB 不可驱逐 Pod
- [优化] `集群管理` *亚马逊云EKS*、*谷歌云GKE*、*微软云AKS* 节点池多项功能及稳定性优化
- [优化] `集群管理` 节点上下架部分失败场景支持重试，任务日志展示优化
- [优化] `资源视图` 支持记忆列宽及上次选中的命名空间，Pod 详情嵌入监控平台事件查询
- [优化] `额度管理` 额度管理页面重构
- [优化] `WebConsole` 支持进入 initContainer，适配 Windows 下的复制快捷键
- [优化] `安全` 修复多处 XSS 风险并升级前端依赖版本
